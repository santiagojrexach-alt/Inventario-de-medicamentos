Bienvenido a Inventario Tarmed

Gestión de psicofármacos para residentes de psiquiatría. Configuremos el servicio en tres pasos.

¿Tenés datos guardados?

Si tenés un JSON exportado de una versión anterior, importalo ahora. Si es la primera vez, empezá con el inventario de ejemplo.

El inventario está configurado. Podés ajustar todos los parámetros en cualquier momento desde Configuración.

Tip: Exportá el JSON regularmente para no perder datos.
